# Audio Slots

目前此目錄預設未附帶第三方音訊素材，遊戲會先使用程式合成的佔位 BGM 與音效。

- `bgm.ogg` / `bgm.mp3` / `bgm.wav`: 背景音樂槽位
- `jump.ogg` / `jump.mp3` / `jump.wav`: 跳躍音效槽位
- `hit.ogg` / `hit.mp3` / `hit.wav`: 撞擊音效槽位
- `death.ogg` / `death.mp3` / `death.wav`: 死亡轉場音效槽位
- `land.ogg` / `land.mp3` / `land.wav`: 落地音效槽位
- `start.ogg` / `start.mp3` / `start.wav`: 開始音效槽位
- `ui-open.ogg` / `ui-open.mp3` / `ui-open.wav`: 開啟設定音效槽位
- `ui-close.ogg` / `ui-close.mp3` / `ui-close.wav`: 關閉設定音效槽位
- `resume.ogg` / `resume.mp3` / `resume.wav`: 繼續遊戲音效槽位
